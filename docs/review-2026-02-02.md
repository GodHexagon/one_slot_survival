# ルールパッケージの確認メモ（2026-02-02）

対象: `src/main/java/com/github/godhexagon/oneslotsurvival/rule`

## 発見事項

### High
- `Exp.add` は大きな `amount` を与えた場合に複数レベルアップを処理できず、`remaining` が負のまま残る可能性がある（1回の加算で最大1レベル想定なら問題なし）。

### Medium
- `SlotBarrierFilling.fillUp` で不正アイテムを回収後に `player.addItem` で再投入しているため、制限スロットに再配置される可能性がある。結果として「不正→回収→再配置」の循環が起きる懸念がある。
- `Exp.clear` が未初期化状態（レベル0）で呼ばれると `getNextLevelExp(0)` が `multiplier^-1` を計算する可能性がある（仕様として許容するか要確認）。

### Low
- `LevelAttribute.setLevel` の Javadoc は「1未満で `IllegalArgumentException`」とあるが、実装は 0 に丸めるだけで例外を投げない（ドキュメント不整合）。
- `RoleLeveledUpTimes.getMain/getSub` が負値になる可能性がある。これが `getAvailableRoleSlots` に渡ると全スロットがロック扱いになりうる（仕様か要確認）。
- `docs/task_list.md` を含めコメントの文字化けが見られるため、ファイルエンコーディングの不一致（UTF-8/Shift-JIS）が疑われる。

## 確認したいこと
- 経験値の加算は「1回の add で最大1レベルアップ」仕様で良いか？
- `fillUp` 後の回収品は「手元に戻す」必要があるか、それともドロップ/破棄で良いか？
