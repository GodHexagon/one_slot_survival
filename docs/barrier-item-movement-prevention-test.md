# バリアアイテム不正移動防止テスト

## アプローチ変更
- ワールドスキャン方式 → **操作時点での防止方式**
- より確実で効率的な制御を実現

## 防ぐべきシチュエーション

### 1. プレイヤーの直接操作
- インベントリ内ドラッグ&ドロップ〇
- バリアアイテムをメインハンド/オフハンドに移動〇
- 防具スロットへの移動〇
- ホットバー選択によるバリアアイテム保持〇
- Shift+クリックによる高速移動〇
- Ctrl+数字キーによる移動〇

### 2. コンテナー間移動
- チェスト、かまど、醸造台、エンチャントテーブル〇
  - チェスト→プレイヤーインベントリ✖
  - プレイヤーインベントリ→チェスト〇
  - シュルカーボックス、エンダーチェストでもテスト〇
- 発見：チェスト・醸造台のスロット１以外を操作できない✖✖
- ホッパーによる自動移動✖
- ディスペンサー/ドロッパーの排出〇外に出ると消える

### 3. 外部システム
- /give コマンドでの取得✖
- 他MODとの相互作用✖
- 管理者による強制移動✖
- クリエイティブモードでの直接取得〇

### 4. 特殊状況
- プレイヤー死亡時のドロップ〇
- ディメンション移動〇
- チャンクロード〇
- チャンクアンロード✖
- サーバー再起動✖
- リログ〇
- プレイヤーがいない間に状態変更✖

## インベントリ画面実装後のテスト項目

### 基本操作テスト
- 〇**ドラッグ&ドロップ阻止テスト**
  - バリアアイテムをマウスで掴めないことを確認
  - ドラッグ開始時点で操作をキャンセル

- [ ] **メインハンドへの移動阻止**
  - バリアアイテムをスロット0に移動できないことを確認
  - 移動試行時にエラーメッセージ表示

- 〇**オフハンドへの移動阻止**
  - バリアアイテムをオフハンドスロットに移動できないことを確認
  - Fキーでの移動も阻止

- 〇**防具スロットへの移動阻止**
  - ヘルメット、チェストプレート、レギンス、ブーツスロットへの移動阻止
  - 防具として着用できないことを確認

- 〇**ホットバー選択時の動作確認**
  - バリアアイテムが配置されたスロットを選択できないことを確認
  - スクロールホイールでの選択も制御

### コンテナーテスト
- ✖**チェストからの取り出し阻止**
  - チェスト内のバリアアイテムをクリック/取り出し不可
  - Shift+クリックでの高速移動も阻止

- 〇**チェストへの格納阻止**
  - プレイヤーインベントリからチェストへの移動阻止
  - 誤操作による格納を防止

- 〇**かまど・醸造台での動作確認**
  - 燃料スロット、素材スロットへの配置阻止
  - 製作結果スロットでの処理確認

- ✖**ホッパーでの自動移動阻止**
  - ホッパーによるバリアアイテム移動の防止
  - 自動ソートシステムでの動作確認

### 特殊状況テスト
- 〇**死亡時のアイテム処理**
  - 死亡時にバリアアイテムがドロップしないことを確認
  - リスポーン後に適切にバリアアイテムが復旧

- 〇**リログ時の状態保持**
  - サーバー再接続後もバリアアイテムが適切に配置
  - 不正な位置のバリアアイテムが自動削除

- ✖**クリエイティブモードでの制御**
  - クリエイティブモードでもバリアアイテム制御が有効
  - 管理者権限での例外処理

- 〇**管理者権限での動作確認**
  - 管理者による意図的な操作の許可設定
  - デバッグモードでの詳細動作確認

### パフォーマンステスト
- [ ] **大量アイテム処理時の動作**
  - インベントリが満杯時の動作確認
  - 大量のバリアアイテムが存在する場合の処理速度

- [ ] **マルチプレイヤー環境**
  - 複数プレイヤー同時操作時の動作
  - サーバー負荷の確認

## 実装優先順位

1. **Phase 1 (最優先)**: InventoryClickEvent, PlayerDropItemEvent, EntityItemPickupEvent
2. **Phase 2 (次優先)**: ContainerClickEvent, ItemTransferEvent, InventoryDragEvent
3. **Phase 3 (低優先)**: CommandEvent, PlayerRespawnEvent, MOD連携

## 成功基準

- バリアアイテムが禁止スロット（1-35）以外に移動できない✖
- プレイヤーの操作でバリアアイテムを不正な位置に配置できない〇
- 外部システム（ホッパー、コマンド等）による不正移動も防止✖
- パフォーマンスへの影響が最小限✖
- デバッグ情報による動作の透明性確保✖
